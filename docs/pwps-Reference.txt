## Add-PWGroupMember


NAME
    Add-PWGroupMember
    
SYNOPSIS
    Adds a User to a Group in the current ProjectWise Datasource.
    
    
SYNTAX
    Add-PWGroupMember [-GroupID] <Int32> [-UserID] <Int32> [<CommonParameters>]
    
    Add-PWGroupMember [-GroupID] <Int32> [-UserName] <String> [<CommonParameters>]
    
    Add-PWGroupMember [-GroupName] <String> [-UserID] <Int32> [<CommonParameters>]
    
    Add-PWGroupMember [-GroupName] <String> [-UserName] <String> [<CommonParameters>]
    
    
DESCRIPTION
    The Add-PWGroupMember cmdlet adds a User to a User Group in the current ProjectWise Datasource.
    
    Users and Groups can be selected either by ID or by name.
    

PARAMETERS
    -GroupID <Int32>
        The ID of the User Group to add to.
        
        Required?                    true
        Position?                    0
        Default value                
        Accept pipeline input?       true (ByPropertyName)
        Accept wildcard characters?  false
        
    -GroupName <String>
        The name of the User Group to add to. Some wildcards (*, ?) are technically allowed, but Group Members can only be added one at a time, so this name must only match one Group.
        
        Required?                    true
        Position?                    0
        Default value                
        Accept pipeline input?       false
        Accept wildcard characters?  false
        
    -UserID <Int32>
        The UserID of the User to add.
        
        Required?                    true
        Position?                    1
        Default value                
        Accept pipeline input?       true (ByPropertyName)
        Accept wildcard characters?  false
        
    -UserName <String>
        The UserName of the User to add. Some wildcards (*, ?) are technically allowed, but Group Members can only be added one at a time, so this name must only match one User.
        
        The two wildcard characters supported are:
         * (matches zero or more characters, starting at the specified position)
         ? (matches any character at the specified position)
        
        Required?                    true
        Position?                    1
        Default value                
        Accept pipeline input?       false
        Accept wildcard characters?  false
        
    <CommonParameters>
        This cmdlet supports the common parameters: Verbose, Debug,
        ErrorAction, ErrorVariable, WarningAction, WarningVariable,
        OutBuffer, PipelineVariable, and OutVariable. For more information, see 
        about_CommonParameters (https:/go.microsoft.com/fwlink/?LinkID=113216). 
    
INPUTS
    None
        You can optionally pipe either User or Group objects to this cmdlet.
    
    
OUTPUTS
    Bentley.ProjectWise.PowerShell.Common.User
        Add-PWGroupMember returns an object that represents the User that was added to the User Group.
    
    
NOTES
    
    
        Add-PWGroupMember requires an open ProjectWise Connection in the current thread.  You can open a Connection with Open-PWConnection before calling Add-PWGroupMember.
        
        Add-PWGroupMember requires an Admin session.  To open an admin session, use the -Admin flag when opening the ProjectWise Connection with Open-PWConnection.
    
    --------------------------  EXAMPLE 1  --------------------------
    
    Add-PWGroupMember -GroupID 3 -UserName admin
    
    Add a User with UserName = admin to the Group with GroupID = 3
    
    
    
    UserID UserName      Description   Type    SecProvider  IsConnected IsDisabled
    ------ --------      -----------   ----    -----------  ----------- ----------
      1    admin                       Logical                   Y           N
    
    --------------------------  EXAMPLE 2  --------------------------
    
    Add-PWGroupMember -GroupID 3 -UserID 2
    
    Add a User with UserID = 2 to the Group with GroupID = 3
    
    
    
    UserID UserName      Description   Type    SecProvider  IsConnected IsDisabled
    ------ --------      -----------   ----    -----------  ----------- ----------
      2    user                        Logical                   N           N
    
    --------------------------  EXAMPLE 3  --------------------------
    
    Add-PWGroupMember -GroupName DomainGroup -UserName admin
    
    Add a User with UserName = admin to the Group with GroupName = DomainGroup
    
    
    
    UserID UserName      Description   Type    SecProvider  IsConnected IsDisabled
    ------ --------      -----------   ----    -----------  ----------- ----------
      1    admin                       Logical                   Y           N

         * (matches zero or more characters, starting at the specified position)
         ? (matches any character at the specified position)
        
        Required?                    false
        Position?                    0
        Default value                
        Accept pipeline input?       false
        Accept wildcard characters?  false

    Open-PWConnection -GUI <SwitchParameter> [-Admin <SwitchParameter>] [<CommonParameters>]
    
    
DESCRIPTION
    The Open-PWConnection cmdlet attempts to connect to a ProjectWise Datasource and keep this connection open for future ProjectWise commands.  This cmdlet must be called before almost all other PWPS commands.
    
    Some commands require an admin session to function properly or return all relevant info.  To open an admin session, use the -Admin flag.
    
    If no username and password are given, the cmdlet will attempt to use SSO to connect to the Datasource.
    
    The connection should always be closed using the Close-PWConnection cmdlet.

        The name of the Datasource to connect to.
        
        Required?                    true
        Position?                    0
        Default value                
        Accept pipeline input?       false
        Accept wildcard characters?  false
        
    -GUI [<SwitchParameter>]
        Perform the login via the graphical user interface.
        
        Required?                    true
        Position?                    named
        Default value                
        Accept pipeline input?       false

## Set-PWAsyncExtractionSetting


NAME
    Set-PWAsyncExtractionSetting
    
SYNOPSIS
    Sets various settings for an Asynchronous Extraction Component in the current ProjectWise Datasource.
    
    
SYNTAX
    Set-PWAsyncExtractionSetting -FilePropertyExtraction <SwitchParameter> -Off <SwitchParameter> [<CommonParameters>]
    
    Set-PWAsyncExtractionSetting -FilePropertyExtraction <SwitchParameter> -On <SwitchParameter> [-UserName <String>] [-Password <Object>] [-MaxDocuments <Int32>] [-RetryTime <Int32>] [<CommonParameters>]
    
    Set-PWAsyncExtractionSetting -FullTextIndexing <SwitchParameter> [-Live <SwitchParameter>] -On <SwitchParameter> [-UserName <String>] [-Password <Object>] [-MaxDocuments <Int32>] [-RetryTime <Int32>] [-SkipSchedule <SwitchParameter>] [<CommonParameters>]
    
    Set-PWAsyncExtractionSetting -FullTextIndexing <SwitchParameter> -Off <SwitchParameter> [<CommonParameters>]
    
    Set-PWAsyncExtractionSetting -ThumbnailExtraction <SwitchParameter> -Off <SwitchParameter> [<CommonParameters>]
    
    Set-PWAsyncExtractionSetting -ThumbnailExtraction <SwitchParameter> -On <SwitchParameter> [-UserName <String>] [-Password <Object>] [-MaxDocuments <Int32>] [-RetryTime <Int32>] [<CommonParameters>]
    
    
DESCRIPTION
    The Set-PWAsyncExtractionSetting cmdlet sets various settings for an Asynchronous Extraction Component in the current ProjectWise Datasource.
    
    The component to modify a setting for must be specified by one of the following flags: -FilePropertyExtraction, -FullTextIndexing, or -ThumbnailExtraction.
    
    The simplest use for Set-PWAsyncExtractionSetting uses either the -On or -Off flag to enable or disable the given Asynchronous Extraction Component.
    
    With the UserName and Password parameters, the user that the component runs as can be set.  Other settings can also be set with the the MaxDocuments and RetryTime parameters.  When the component is specified as FullTextIndexing, the -SkipSchedule flag can also be used to skip the Schedule for Document Property Indexing.

    -FilePropertyExtraction [<SwitchParameter>]
        If set, sets various settings for the File Property Extraction Component.
        
        Required?                    true
        Position?                    named
        Default value                
        Accept pipeline input?       false
        Accept wildcard characters?  false
        
    -FullTextIndexing [<SwitchParameter>]
        If set, sets various settings for the Full Text Indexing Component.
        
        Required?                    true
        Position?                    named
        Default value                
        Accept pipeline input?       false
        Accept wildcard characters?  false
        
    -Live [<SwitchParameter>]
        
        
        Required?                    false
        Position?                    named
        Default value                
        Accept pipeline input?       false
        Accept wildcard characters?  false
        
    -MaxDocuments <Int32>

        Required?                    false
        Position?                    named
        Default value                
        Accept pipeline input?       false
        Accept wildcard characters?  false

        If set, disables the given component.
        
        Required?                    true
        Position?                    named
        Default value                
        Accept pipeline input?       false
        Accept wildcard characters?  false
        
    -On [<SwitchParameter>]
        If set, enables the given component.
        
        Required?                    true

        Accept pipeline input?       false
        Accept wildcard characters?  false
        
    -Password <Object>
        The password of the User this component should run as.  If a Password is provided, the UserName parameter must also be provided. Password can be passed as plain text (String) or SecureString object. It is recommended to use SecureString (see examples).
        
        Required?                    false
        Position?                    named
        Default value                
        Accept pipeline input?       false
        Accept wildcard characters?  false
        
    -RetryTime <Int32>
        The amount of time (in minutes) to wait before retrying extraction (must be between 10 and 1440 minutes).
        
        Required?                    false
        Position?                    named
        Default value                
        Accept pipeline input?       false
        Accept wildcard characters?  false
        
    -SkipSchedule [<SwitchParameter>]
        If set, the component will skip the Schedule for document property indexing.  Only applicable to the Full Text Indexing component.
        
        Required?                    false
        Position?                    named
        Default value                
        Accept pipeline input?       false
        Accept wildcard characters?  false
        
    -ThumbnailExtraction [<SwitchParameter>]
        If set, sets various settings for the Thumbnail Extraction Component.
        
        Required?                    true
        Position?                    named
        Default value                
        Accept pipeline input?       false
        Accept wildcard characters?  false

    Set-PWAsyncExtractionSetting -FilePropertyExtraction -Off
    
    Turn Off File Property Extraction
    
    
    
    --------------------------  EXAMPLE 2  --------------------------
    
    Set-PWAsyncExtractionSetting -FilePropertyExtraction -On
    
    Turn On File Property Extraction
    
    
    
    --------------------------  EXAMPLE 3  --------------------------
    
    Set-PWAsyncExtractionSetting -FilePropertyExtraction -On -UserName admin -Password admin
    
    Turn On File Property Extraction and set it to run as a particular User
    
    
    
    --------------------------  EXAMPLE 4  --------------------------
    
    Set-PWAsyncExtractionSetting -ThumbnailExtraction -On -MaxDocuments 100 -RetryTime 15
    
    Turn On File Thumbnail Extraction and set MaxDocuments and RetryTime
    
    
    
    --------------------------  EXAMPLE 5  --------------------------
    
    Set-PWAsyncExtractionSetting -FullTextIndexing -On -Live
    
    Turn On Full Text Indexing and enable Live Extraction (FullTextIndexing *only*)
    
    
    
    --------------------------  EXAMPLE 6  --------------------------
    
    Set-PWAsyncExtractionSetting -FullTextIndexing -On -SkipSchedule
    
    Turn On Full Text Indexing and set it to Skip Schedule for Document Property Indexing (FullTextIndexing *only*)

        Update-PWUser requires an Admin session.  To open an admin session, use the -Admin flag when opening the ProjectWise Connection with Open-PWConnection.
        It is recommended to store and pass password as secure string object.
    
    --------------------------  EXAMPLE 1  --------------------------
    
    $userObj = Get-PWUser -UserID 4
    $userObj.UserName = "Changed.Name"
    $userObj.Description = "Some New Description"
    $userObj.Email = "changed@email.com"
    $userObj.Type = "Windows"
    $userObj.SecProvider = "NEWDOMAIN"
    $userObj.Identity = "external_identity@email.com"
    Update-PWUser -User $userObj | Format-List
    
    Modifies various user properties.

    Email            : changed@email.com

    Identity         : external_identity@email.com
    IdentityProvider :
    ID               : 4
    Name             : Changed.Name
    
    --------------------------  EXAMPLE 2  --------------------------
    
    Get-PWUser -UserID 1 | Update-PWUser -Password N3wPassw0rd

    UserID UserName      Description           Type     SecProvider  IsConnected IsDisabled
    ------ --------      -----------           ----     -----------  ----------- ----------
      1    admin         An admin user         Logical                    Y           N
