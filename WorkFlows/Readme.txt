WorkFlows
=========

Purpose
-------
Scripts in this folder document ProjectWise workflows: their states, the transitions
between them and whether they are used.

Typical tasks
-------------
- Draw a workflow as a diagram.
- Find workflows that are not assigned to any folder.

Before running
--------------
- Requires Windows PowerShell 5.1 x64 and the pwps_dab module.
- Scripts here are read-only.
- Each script writes a timestamped .LastRun.log transcript beside itself.
