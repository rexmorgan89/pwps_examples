General
=======

Purpose
-------
Utility scripts that are not tied to one ProjectWise area: module update checks and
workstation checks.

Typical tasks
-------------
- Check whether installed ProjectWise PowerShell modules have updates available.
- Check that a workstation has the right PowerShell edition, bitness and modules.

Before running
--------------
- Requires Windows PowerShell 5.1 x64. Check each script's help for module needs.
- Never store passwords, tokens or webhook URLs in the scripts; pass them in at run time.
